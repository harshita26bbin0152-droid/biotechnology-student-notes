# Biotechnology Student Notes

## Introduction to Biotechnology

Biotechnology is the use of living organisms,
cells and biological processes to develop
useful products and technologies.

## Applications of Biotechnology

1. Medical Biotechnology
2. Agricultural Biotechnology
3. Industrial Biotechnology
4. Environmental Biotechnology

## Basic Biological Concepts

- DNA: Stores genetic information.
- RNA: Helps in protein synthesis.
- Cell: Basic structural unit of life.
- Protein: Performs important functions in cells.

## Conclusion

Biotechnology plays an important role in
medicine, agriculture and scientific research.
